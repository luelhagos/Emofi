# data/

Downloaded data from the [trivox-tts](https://drive.google.com/drive/folders/1AMTuWvHln3T7sZAgLrt_7k8rKNE9Gm5n?usp=drive_link) Google Drive goes here.
Unzip so you end up with these two folders:

- `data/MEAD/`            preprocessed training data: `mel/ pitch/ energy/ duration/
                          face_emb_cache/ spk_emb_cache/ speakers.json stats.json
                          train.txt val.txt test.txt`
- `data/MEAD_processed/`  real test wavs (for the emotion2vec / SER real-audio ceiling)
